# 水产养殖气象灾害应对要点

> 适用：桂花鱼（鳜鱼）、罗非鱼等佛山地区主养品种。本文为农技资料整理稿。

## 一、溶氧与天气的关系

### 基本原理
- 水体溶氧来源主要为浮游植物光合作用与空气溶解
- 连续阴雨、大雾、闷热低压天气，光合作用减弱且气压低，溶氧显著下降
- 水温越高，水体饱和溶氧越低，鱼类耗氧量反而上升
- 暴雨后表层水温骤降易引发"泛池"（上下水层对流，底层缺氧水上翻）

### 浮头预警信号
- 鱼类在黎明前密集浮于水面、张口呼吸
- 摄食量突然下降
- 水体发出腥臭味，水色突变

## 二、低温寒潮应对

### 罗非鱼的耐寒临界
- 水温 ≤ 16℃：摄食明显减少
- 水温 ≤ 12℃：基本停止摄食
- 水温 ≤ 10℃：开始出现死亡
- 水温 ≤ 8℃：大量死亡风险

### 桂花鱼（鳜鱼）的耐寒特点
- 属温水性鱼类，越冬期需保持水温相对稳定
- 水温骤降超过 3℃/天 易产生强应激反应

### 防御措施
- 寒潮来临前加深池塘水位至 1.8—2.5 米，利用底层水温相对稳定
- 搭建越冬棚或覆盖保温薄膜（罗非鱼越冬常用方式）
- 寒潮期间减少或停止投喂，降低代谢耗氧
- 水温回升前不要急于恢复投喂，待水温稳定 2—3 天后再逐步增量
- 有条件的可采用地下水补充、增温设备（注意用电安全与成本）
- 提前做好上市计划，规格达标鱼优先出塘，降低越冬风险

### 预警关注
当预报日最低气温 ≤ 8℃ 或 48 小时内降温幅度 ≥ 8℃ 时，应启动防寒应急准备。

## 三、台风暴雨应对

### 台风来临前
- 检查加固塘埂，防止溃堤逃鱼
- 检查并加固增氧设备、投饵机电路，做好防雨防潮
- 提前降低水位，预留蓄洪空间防止漫埂
- 准备柴油发电机或备用增氧设备，防范停电
- 台风前 1—2 天减少投喂量（降至平时 50%），减少排泄物耗氧
- 检修防逃设施（拦鱼栅、网片）

### 台风过后
- 立即检查塘埂、防逃设施是否损毁，及时修补
- 检测水质指标：pH、氨氮、亚硝酸盐、溶氧
- 暴雨后水体 pH 常下降，可适量泼洒生石灰调节（用量按水体体积计算，一般每亩每米水深 10—15 千克）
- 全池泼洒消毒剂（如聚维酮碘、二氧化氯，按产品说明使用）预防细菌性疾病
- 停食 1—2 天后逐步恢复投喂，并拌喂维生素 C、免疫多糖增强抗应激能力
- 及时清理死鱼并无害化处理，严禁随意丢弃

## 四、闷热低压天气的泛塘防控

### 易发条件
- 夏季连续阴雨、大雾、无风天气
- 台风来临前的低压闷热时段
- 傍晚至次日黎明前为浮头高发时段

### 防控措施
- 开启增氧机：晴天中午开 1—2 小时促进上下水层交换；阴天清晨开机；连绵阴雨半夜开机
- 控制养殖密度与投喂量，减少有机负荷
- 定期使用微生物制剂（芽孢杆菌、光合细菌）改善水质
- 定期换注新水，每次换水量控制在总量的 20%—30%
- 配备应急增氧药物（过氧化钙、过碳酸钠等），浮头时立即施用

## 五、高温季节管理

### 判断指标
水温持续 ≥ 32℃。

### 主要影响
- 水体溶氧饱和度下降，鱼类摄食与生长受抑
- 蓝藻易暴发，产生藻毒素
- 亚硝酸盐、氨氮升高，病害风险增加

### 管理措施
- 加深水位，设置遮阳网或种植水生植物遮阴
- 调整投喂时间至早晨与傍晚凉爽时段
- 减少投喂量 10%—20%，避免残饵污染水质
- 增加换水频次，保持水体清新
- 加强增氧，特别是夜间增氧
